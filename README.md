# Агентная обвязка

Заготовка для технического интервью. Поднимите окружение заранее, на собеседовании время на установку зависимостей тратить не будем.

## Запуск

```
cp .env.example .env      # ключ и адрес эндпоинта пришлём отдельно
make setup
make check
```

`make check` должен быть зелёным. Если нет — напишите нам до собеседования.

## Что внутри

`app/harness.py` — обвязка вокруг LLM. Она принимает задачу, ведёт диалог с моделью, вызывает инструменты, которые модель запрашивает, возвращает результаты обратно в диалог и заканчивает, когда модель дала текстовый ответ.

Инструментов два: `search` ищет сотрудника, `fetch_profile` отдаёт его карточку. Они уже написаны, трогать их не нужно.

Попробуйте:

```
make run TASK="кто руководитель у Ковалёва"
```

## Задача

Обвязка работает, пока модель ведёт себя хорошо. Модель за эндпоинтом слабая и ведёт себя хорошо не всегда.

Ваша задача — сделать так, чтобы обвязка не падала и не зависала при любом поведении модели. Конкретные требования получите на собеседовании устно, по одному.

Перед собеседованием запустите `make run` несколько раз с разными задачами и посмотрите, где оно ломается. С этого и начнём разговор.

Кода писать заранее не нужно.

## Ограничения

Адрес эндпоинта и имя модели читайте из окружения, не хардкодьте — мы будем переключать провайдера.

## Формат собеседования

Час, шарим экран. Инструменты любые, включая AI-ассистентов — работайте так, как привыкли работать. Последние 20 минут разбираем решение.
